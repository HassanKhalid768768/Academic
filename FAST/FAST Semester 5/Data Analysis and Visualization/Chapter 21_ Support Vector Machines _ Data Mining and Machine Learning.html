Support Vector Machines
In this chapter we describe Support Vector Machines (SVMs), a classification method
based on maximum margin linear discriminants, t hat is, the goal is to find the optimal
hyperplane that maximizes the gap or margin be tween the classes. Furthe r, we can use
the kernel trick to find the optimal nonlinear decision boundary between classes, which
corresponds to a hyperplane in some hig h-dimensional “nonlinear” space.
